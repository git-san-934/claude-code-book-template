# claude-code-book-template

## 外食履歴アプリ（音声入力対応）

音声で話しかけるだけで外食の記録（日付・店名・ジャンル・金額・メモ）を残せる、
ビルド不要の静的Webアプリです。

### 使い方

```sh
python3 -m http.server 8000
```

上記でサーバーを起動し、ブラウザで `http://localhost:8000` を開いてください。
（ブラウザのマイク許可が必要です。Chrome系ブラウザ推奨）

「音声で記録する」ボタンを押して、例えば
「今日、渋谷のラーメン屋で1200円使いました」
のように話すと、日付・店名・ジャンル・金額を自動で読み取ってフォームに入力します。
内容を確認・修正してから「保存する」を押すと履歴に追加されます。

音声認識に対応していないブラウザでは、フォームからの手入力で利用できます。

### データの保存先

すべての記録はブラウザの `localStorage` に保存されます（サーバー送信なし）。

### ファイル構成

- `index.html` — ページ構造
- `style.css` — スタイル
- `app.js` — 音声認識・解析・履歴のCRUD・集計ロジック
