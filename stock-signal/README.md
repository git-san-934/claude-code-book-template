# 株シグナル（買い時・売り時判定）

銘柄ごとに終値を入力していくだけで、移動平均線とRSIから
買い時・売り時の目安を判定する、ビルド不要の静的Webアプリです。

### 使い方

リポジトリのルートで以下を実行し、ブラウザで
`http://localhost:8000/stock-signal/` を開いてください。

```sh
python3 -m http.server 8000
```

1. 「＋ 銘柄を追加」で銘柄名・コードを登録します。
2. 日付と終値を入力して「記録する」を押すと履歴に追加されます。
3. 終値が25件以上になると、5日移動平均線と25日移動平均線から
   「買い」「売り」「上昇継続」「下降継続」「様子見」を判定します。
   - ゴールデンクロス（短期線が長期線を上抜け）→ 買い
   - デッドクロス（短期線が長期線を下抜け）→ 売り
4. RSI（14日）もあわせて表示し、70以上で買われすぎ、30以下で
   売られすぎの注意を表示します。
5. 価格の推移は折れ線チャートで確認できます。

判定はあくまで一般的なテクニカル指標に基づく目安であり、
投資判断を保証するものではありません。

### データの保存先

すべての記録はブラウザの `localStorage` に保存されます（サーバー送信なし）。

### ファイル構成

- `index.html` — ページ構造
- `style.css` — スタイル
- `app.js` — 銘柄・終値のCRUD、移動平均線／RSI計算、判定ロジック、チャート描画
